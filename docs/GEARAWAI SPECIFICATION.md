# MASTER PROMPT พัฒนาเว็บไซต์ E-Commerce GEARAWAI ครบทั้ง 20 ระบบ

## 1. บทบาทและเป้าหมายของโปรเจกต์

คุณคือ Senior Full-Stack Developer, UIUX Designer และ Database Architect ที่มีความเชี่ยวชาญในการพัฒนาเว็บไซต์ E-Commerce

จงออกแบบและพัฒนาเว็บไซต์พาณิชย์อิเล็กทรอนิกส์ชื่อ GEARAWAI สำหรับจำหน่ายอุปกรณ์ Gaming Gear และอุปกรณ์เทคโนโลยีสารสนเทศ (IT Equipment) โดยพัฒนาเป็นเว็บไซต์ที่สามารถใช้งานได้จริง มีทั้งระบบหน้าบ้าน (Frontend) สำหรับลูกค้า และระบบหลังบ้าน (Backend  Admin Dashboard) สำหรับผู้ดูแลระบบ

เว็บไซต์ต้องมีหน้าตาทันสมัย ใช้งานง่าย รองรับทุกขนาดหน้าจอ และมีระบบจัดการข้อมูลที่เชื่อมโยงกับฐานข้อมูลอย่างเป็นระบบ

### ระบบที่ 18 ระบบฐานข้อมูล (Database System)

1. profiles — ข้อมูลสมาชิก
2. products — ข้อมูลสินค้า
3. categories — หมวดหมู่สินค้า
4. brands — แบรนด์สินค้า
5. product_images — รูปภาพสินค้า
6. wishlists — รายการโปรด
7. wishlist_items — สินค้าในรายการโปรด
8. carts — ตะกร้าสินค้า

13. bookings — ข้อมูลการจองบริการ

ข้อกำหนดด้านฐานข้อมูล
- กำหนด Primary Key และ Foreign Key
- กำหนดความสัมพันธ์ระหว่างตาราง
- ตรวจสอบข้อมูลก่อนบันทึก
- ใช้ Transaction ในการดำเนินการที่เกี่ยวข้องกับยอดเงินและคะแนน
- ใช้ Supabase Authentication
- กำหนด Row Level Security (RLS)
- สมาชิกเข้าถึงได้เฉพาะข้อมูลของตนเอง
- Admin จัดการข้อมูลตามสิทธิ์ที่ได้รับ
- ห้ามเปิดเผย Secret Key ใน Frontend

## 7. ข้อกำหนดด้าน Responsive Design

## 9. ข้อกำหนดด้านการทำงานจริง

ห้ามสร้างเว็บไซต์ที่มีเพียงหน้าตาสวยงามแต่ไม่สามารถใช้งานได้

ระบบทั้งหมดต้องเชื่อมโยงกัน เช่น

1. Admin เพิ่มสินค้าแล้วสินค้าต้องแสดงในหน้า Shop
2. Admin เปลี่ยนราคาสินค้าแล้วราคาต้องอัปเดต
3. Admin ปรับ Stock แล้วจำนวนสินค้าคงเหลือต้องเปลี่ยน
4. ลูกค้าเพิ่มสินค้าลง Cart แล้วต้องแสดงในหน้าตะกร้า
5. ลูกค้าสั่งซื้อแล้วต้องสร้าง Order ในฐานข้อมูล
6. สมาชิกตรวจสอบประวัติคำสั่งซื้อได้
7. Admin ตรวจสอบคำสั่งซื้อได้
8. การชำระเงินต้องเชื่อมโยงกับ Order
9. คะแนนสะสมต้องคำนวณจากคำสั่งซื้อที่เข้าเงื่อนไข
10. Wishlist ต้องแยกตามบัญชีสมาชิก
11. โปรโมชั่นต้องแสดงตามวันเริ่มต้นและวันสิ้นสุด
12. รายงานต้องดึงข้อมูลจากฐานข้อมูลจริง
13. ข้อความจาก Contact Form ต้องปรากฏในระบบหลังบ้าน
14. การจองบริการต้องปรากฏในระบบจัดการการจอง

## 15. คำสั่งสุดท้าย

เริ่มต้นจากการวิเคราะห์โครงสร้างเว็บไซต์และวางแผนฐานข้อมูลก่อน จากนั้นพัฒนาระบบตาม Phase ที่กำหนด

อย่าสร้างทุกหน้าเป็นเพียง Static UI แต่ต้องทำให้ปุ่ม แบบฟอร์ม การค้นหา การกรอง การเพิ่มสินค้า การจัดการข้อมูล และการเชื่อมต่อฐานข้อมูลทำงานได้จริง

ให้รักษารูปแบบการออกแบบ GEARAWAI ให้สม่ำเสมอทุกหน้า โดยใช้ธีม Dark Gaming  Tech และสีที่กำหนด

หากมีข้อมูลใดที่ยังไม่ได้ระบุ ให้ใช้ข้อมูลตัวอย่างที่แก้ไขได้ และแจ้งให้ทราบว่าเป็นข้อมูลตัวอย่าง ห้ามแต่งข้อมูลจริง เช่น ที่อยู่ เบอร์โทรศัพท์ หรือข้อมูลบัญชีร้านขึ้นมาเอง

เป้าหมายสุดท้ายคือเว็บไซต์ GEARAWAI E-Commerce ที่มีระบบหน้าบ้านและหลังบ้านครบ 20 ระบบ มีฐานข้อมูลเชื่อมโยงกัน ใช้งานได้จริง และสามารถนำไปพัฒนาต่อเป็นโครงงานได้
