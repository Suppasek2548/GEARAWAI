# GEARAWAI PROJECT CONTEXT

## 1. ข้อมูลโครงงาน
ชื่อโครงงาน: เว็บไซต์พาณิชย์อิเล็กทรอนิกส์อุปกรณ์เกมมิ่งเกียร์และอุปกรณ์เทคโนโลยีสารสนเทศ

ชื่อร้าน: GEARAWAI

Slogan: LEVEL UP YOUR GEAR

ประเภทเว็บไซต์: E-Commerce สำหรับจำหน่าย Gaming Gear และอุปกรณ์ IT

## 2. วัตถุประสงค์
- พัฒนาเว็บไซต์สำหรับนำเสนอและจำหน่ายสินค้าออนไลน์
- เพิ่มช่องทางในการเข้าถึงสินค้า Gaming Gear และอุปกรณ์ IT
- อำนวยความสะดวกในการค้นหาและเลือกซื้อสินค้า
- พัฒนาระบบสมาชิกและระบบจัดการข้อมูลสำหรับผู้ดูแล
- นำความรู้ด้านการพัฒนาเว็บไซต์และฐานข้อมูลมาใช้ในโครงงาน

## 3. กลุ่มสินค้า
- Gaming Mouse
- Gaming Keyboard

- Computer Accessories

## 4. กลุ่มผู้ใช้งาน
Guest: ผู้เข้าชมเว็บไซต์ สามารถดูและค้นหาสินค้าได้

Member: สมาชิก สามารถจัดการบัญชี ใช้รายการโปรด ตะกร้าสินค้า และใช้งานระบบสมาชิกได้

Admin: ผู้ดูแลระบบ สามารถจัดการสินค้า หมวดหมู่ ราคา สต็อก โปรโมชั่น และข้อมูลที่เกี่ยวข้องได้

## 7. แนวทางการออกแบบ
ใช้สีหลัก #1F06AC, #0F42C0, #5882E8 และ #E3EF4F

ออกแบบเว็บไซต์ให้มีเอกลักษณ์ด้าน Gaming Gear ใช้พื้นหลังโทนเข้ม มีองค์ประกอบสีน้ำเงินและม่วง พร้อมสีเขียวมะนาวสำหรับเน้นจุดสำคัญ

เว็บไซต์ต้องดูทันสมัย เป็นระเบียบ ใช้งานง่าย และรองรับทุกขนาดหน้าจอ

## 8. ข้อกำหนด
- ระบบต้องเชื่อมต่อฐานข้อมูลจริง
- ระบบหน้าบ้านและหลังบ้านต้องทำงานร่วมกัน
- ข้อมูลสินค้าและสต็อกต้องสามารถจัดการได้
- ต้องกำหนดสิทธิ์การใช้งานตามบทบาท
- ต้องตรวจสอบความปลอดภัยของข้อมูล
- ข้อมูลตัวอย่างต้องแยกจากข้อมูลจริงอย่างชัดเจน
