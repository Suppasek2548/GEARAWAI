# GEARAWAI — คู่มือการเข้าสู่ระบบและใช้งาน Admin

> ส่งมอบตาม SPEC หัวข้อ 13 ข้อ 11 · อ้างอิงการออกแบบ: `GEARAWAI_ADMIN_DESIGN.md` · ฉบับ Phase 6 (12 พ.ย. 2026)
> ระบบชำระเงินเป็น **Demo** — การ "ยืนยันการชำระ" ในหลังบ้านไม่ได้หมายถึงได้รับเงินจริง

## 1. การเข้าสู่ระบบ

1. เปิด `http://localhost:3000/login` แล้วเข้าสู่ระบบด้วยบัญชีที่มี `role = admin` (เช่น `admin.demo@example.com`) → ระบบพาไป `/admin`
2. ถ้าเปิด `/admin` โดยยังไม่ Login จะถูกพาไปหน้า Login ก่อน · ถ้าเป็นสมาชิกทั่วไปจะเห็นหน้า **403** (ไม่มีข้อมูล Admin)
3. ออกจากระบบ: ปุ่ม **ออกจากระบบ** มุมขวาบน → ยืนยัน

**ตั้ง Admin คนแรก** (ทำครั้งเดียวใน Supabase → SQL Editor หลังสมัครบัญชีผ่านหน้าเว็บ):

```sql
update public.profiles set role = 'admin' where email = 'admin.demo@example.com';
```

> ไม่มีปุ่มเปลี่ยนบทบาทในหน้าเว็บ (ป้องกันการยกสิทธิ์ตัวเอง) · Admin ระงับบัญชีของตนเองไม่ได้

## 2. หน้าจอหลัก

- **Sidebar 18 เมนู** แบ่งกลุ่ม Catalog / Sales / Customers / Marketing / Services / Insights / Content · ตัวเลขบนเมนู = งานรอทำ (แจ้งชำระรอตรวจ, การจองรอยืนยัน, ข้อความใหม่, สินค้าสต็อกต่ำ, การแลกรางวัลรอส่งมอบ)
- **Dashboard Overview** (`/admin`): ยอดขาย (เฉพาะ Order ชำระแล้ว/จัดส่ง/สำเร็จ), จำนวน Order, ลูกค้า, สินค้า, กราฟยอดขาย, หมวดขายดี, งานรอทำ, แจ้งเตือนสต็อก, Order ล่าสุด · เลือกช่วงวันที่ได้ (วันนี้ / 7 วัน / 30 วัน / กำหนดเอง — เวลาไทย)
- ทุกการบันทึกแสดง Toast ผลลัพธ์ · การกระทำที่ย้อนกลับไม่ได้ (ลบ, ยกเลิก, ปิดงาน, ระงับบัญชี) มีกล่องยืนยันเสมอ
- หน้าร้านอัปเดตทันทีหลังบันทึก (กด Refresh หน้าร้านเพื่อดู)

## 3. งานประจำวัน: คำสั่งซื้อ → ชำระเงิน → จัดส่ง

| ขั้น | เมนู | ทำอะไร | ผลในระบบ |
|---|---|---|---|
| 1 | **Payments** (กรอง "รอตรวจสอบ") | เปิดดูสลิป (ถ้ามี) → **ยืนยัน** หรือ **ปฏิเสธ** พร้อมเหตุผล | ยืนยัน → Order "ชำระแล้ว" และนับยอดขาย (`sold_count`) · ปฏิเสธ → Order กลับ "รอชำระเงิน" สมาชิกแจ้งชำระใหม่ได้ |
| 2 | **Orders** → เปิด Order | **บันทึก → จัดส่งแล้ว** (ใส่เลขพัสดุได้) | Order "จัดส่งแล้ว" |
| 3 | **Orders** → เปิด Order | **ปิดงาน — สำเร็จ** | Order "สำเร็จ" (อ่านอย่างเดียว) และ **ให้คะแนนสมาชิกอัตโนมัติ** = (ยอดสินค้า − ส่วนลดคูปอง) ÷ 100 ไม่รวมค่าส่ง |
| — | **Orders** | ยกเลิก Order (ต้องใส่เหตุผล) | คืนสต็อก · คืนสิทธิ์คูปอง · ถ้าชำระแล้ว ยอดขายถูกหักคืนและการชำระเป็น "Voided" |

> ข้ามขั้นไม่ได้ (เช่น ชำระแล้ว → สำเร็จ ทันที) · ปิดงานซ้ำไม่ได้ จึงไม่ได้คะแนนซ้ำ

## 4. สินค้าและสต็อก (Catalog)

**Products** — เพิ่ม/แก้ไขสินค้า
- ฟิลด์บังคับ: SKU รูปแบบ `GA-XX-000` (ห้ามซ้ำ), ชื่อ, Slug, แบรนด์, หมวดหมู่, ราคา > 0 · ราคาลด (ถ้ามี) ต้องน้อยกว่าราคาปกติ
- สร้างสินค้าใหม่แล้วระบบพาไปส่วน **รูปภาพ**: อัปโหลด (JPG/PNG/WebP ไม่เกิน 2 MB) หรือเลือกจากคลัง · ตั้ง **ภาพหลัก** ได้ 1 ภาพ · เลื่อนลำดับได้
- **Specifications**: เพิ่มแถว Key/Value · **แนะนำ (Featured)**: ติ๊กเพื่อแสดงบนหน้าแรก
- **ปิดการขาย** = เปลี่ยนสถานะเป็น inactive → หายจากหน้าร้านทันที (ลิงก์เดิมเป็น "ไม่พบสินค้า") แต่ยังอยู่ในหลังบ้าน
- **ลบได้เฉพาะสินค้าที่ไม่เคยถูกสั่งซื้อ** — ถ้ามีประวัติการสั่งซื้อ ระบบแนะนำให้ปิดการขายแทน

**Stock** — แก้จำนวนสต็อกได้ที่เมนูนี้เท่านั้น (หน้าแก้ไขสินค้าแก้สต็อกไม่ได้)
- กด **ปรับสต็อก** → เลือก **รับเข้า (+)** หรือ **ปรับปรุง (±)** → ใส่จำนวนและหมายเหตุ
- สต็อกหลังปรับติดลบไม่ได้ · ทุกครั้งบันทึกประวัติ (ดูได้ที่ลิงก์ประวัติของสินค้า)
- ป้ายหน้าร้าน: เหลือ ≤ เกณฑ์ (ค่าเริ่มต้น 5) = "เหลือน้อย" · 0 = "สินค้าหมด" (ปุ่มซื้อถูกปิด)
- ⚠️ หมายเหตุการปรับให้ชัดเจน — การปรับผิดต้องแก้ด้วยการปรับย้อน (ประวัติยังอยู่)

**Categories / Brands** — ลบหมวด/แบรนด์ที่ยังมีสินค้าไม่ได้ (ย้ายสินค้าก่อน หรือปิดใช้งานแทน)

**Images** — คลังภาพทั้งเว็บ แยกหมวด (product, banner, category, gallery, team ฯลฯ)
- ภาพหมวด **gallery** แสดงในหน้า About อัตโนมัติ
- ลบภาพที่ยังถูกใช้อยู่ไม่ได้ — ระบบแจ้งว่าใช้อยู่ที่ไหน (เช่น "สินค้า: … (SKU)")

## 5. สมาชิก คะแนน และรางวัล (Customers)

**Customers** — ดูข้อมูล คำสั่งซื้อ คะแนน ของสมาชิก
- **ระงับบัญชี**: สมาชิกยัง Login ได้ แต่สั่งซื้อ จองบริการ แลกรางวัล และรับคูปองไม่ได้ · **เปิดใช้งานบัญชี** เพื่อคืนสิทธิ์
- **แก้วันเกิด**: ใช้เมื่อสมาชิกแก้เองครบสิทธิ์แล้ว (สมาชิกตั้งเองได้ 1 ครั้ง + แก้ได้อีก 1 ครั้ง)

**Points** — ปรับคะแนนด้วยมือ: เลือกสมาชิก → จำนวน (+/−) → **เหตุผล (บังคับ)** · คะแนนหลังปรับติดลบไม่ได้

**Rewards** — 2 แท็บ
- **คำขอแลก**: **ส่งมอบแล้ว** (เมื่อมอบของให้สมาชิก) หรือ **ยกเลิก** พร้อมเหตุผล → คืนคะแนนและคืนจำนวนของรางวัลอัตโนมัติ
- **ของรางวัล**: เพิ่ม/แก้ชื่อ คะแนนที่ใช้ จำนวนคงเหลือ ภาพ

## 6. การตลาด (Marketing)

**Promotions** — ส่วนลด % หรือจำนวนเงิน ช่วงเวลา (เวลาไทย) และสินค้าที่เข้าร่วม
- สถานะ: กำลังใช้งาน / ตั้งเวลาไว้ / หมดอายุ / ปิดอยู่ · ติ๊ก "แสดงบนหน้าแรก" เพื่อขึ้น Homepage
- หลังสร้างใหม่ ระบบพาไปเลือก **สินค้าที่เข้าร่วม** → **บันทึกสินค้าที่เข้าร่วม**
- ราคาในร้าน = ค่าต่ำสุดของ (ราคาปกติ, ราคาลด, ราคาโปรโมชั่น) — ไม่ซ้อนส่วนลด · % ต้องไม่เกิน 100 · วันสิ้นสุดต้องหลังวันเริ่ม

**Coupons** — ประเภท general (ใช้รหัส) หรือ birthday (แม่แบบสิทธิ์วันเกิด)
- กำหนด % หรือจำนวนเงิน, ส่วนลดสูงสุด, ยอดขั้นต่ำ, จำนวนครั้งรวม/ต่อคน, ช่วงเวลา
- คอลัมน์ **ใช้ไป** นับอัตโนมัติ (แก้เองไม่ได้) · คูปองที่ถูกใช้แล้วลบไม่ได้ → ปิดใช้งานแทน
- 1 คำสั่งซื้อใช้ได้ 1 คูปอง · ส่งฟรีคิดจากยอดสินค้า **ก่อน** หักคูปอง

## 7. บริการและการจอง (Services)

**Services** — เพิ่ม/แก้บริการ ราคา ระยะเวลา · ปิดสถานะ = หายจากหน้า `/booking` · ลบได้เฉพาะบริการที่ยังไม่มีการจอง
**Bookings** — กรองตามสถานะ/บริการ → **ยืนยัน** / **เสร็จสิ้น** / **ยกเลิก** (ใส่หมายเหตุได้) · ช่วงเวลาที่ยกเลิกกลับมาว่างให้จองทันที · ชำระค่าบริการที่ร้าน (ไม่ผ่านระบบออนไลน์)

## 8. รายงาน (Reports & Analytics)

- 5 แท็บ: Sales / Orders / Best Selling Products / Customers / Categories · ใช้ตัวกรองวันที่ร่วมกัน (เวลาไทย รวมวันสุดท้าย)
- ยอดขายนับเฉพาะ Order **ชำระแล้ว / จัดส่งแล้ว / สำเร็จ** · ไม่นับ ยกเลิก หรือยังไม่ชำระ
- สลับ **รวม / ไม่รวม Demo Data** ได้ · ยอดในแท็บสินค้า/หมวดคิดจากราคาสินค้าก่อนหักคูปอง ไม่รวมค่าส่ง
- **Export Excel**: ได้ไฟล์ `.xlsx` 5 ชีต พร้อมหัวรายงาน (ชื่อร้าน ช่วงวันที่ วันเวลาที่ออก)
- **พิมพ์ / บันทึก PDF**: เปิดหน้า Print → กด "พิมพ์ / บันทึกเป็น PDF" → เลือกปลายทาง **บันทึกเป็น PDF** (ภาษาไทยแสดงถูกต้อง) · เลือก "พิมพ์ทุกรายงาน" ได้

## 9. ข้อความติดต่อและการตั้งค่า (Content)

**Contact Messages** — ค่าเริ่มต้นแสดงข้อความ "ใหม่" · เปิดอ่านแล้วเปลี่ยนเป็น "อ่านแล้ว" อัตโนมัติ · **ตอบกลับทางอีเมล** (เปิดโปรแกรมอีเมลพร้อมหัวข้อ "Re: …") → แล้วกด **ทำเครื่องหมายว่าตอบแล้ว** · **เก็บถาวร** แทนการลบ (ลบแล้วกู้คืนไม่ได้)

**Settings** — 7 แท็บ (บันทึกทีละแท็บ)

| แท็บ | ตั้งค่า |
|---|---|
| Store | ชื่อร้าน, Slogan, Tagline, Hero (ภาพ 3 ขนาด, ข้อความ/ลิงก์ปุ่ม) |
| About | ประวัติร้าน, จุดเด่น (1 บรรทัด = 1 ข้อ), ทีมงาน (เพิ่ม/แก้/ลำดับ/ซ่อน) — ห้ามแต่งชื่อบุคคลจริงขึ้นเอง |
| Contact | เบอร์, อีเมล, ที่อยู่, Google Maps Embed URL, Social links, ✓ ข้อมูลตัวอย่าง |
| Commerce | ค่าส่ง, ยอดขั้นต่ำส่งฟรี, กี่บาท = 1 คะแนน, คูปองแม่แบบวันเกิด |
| Payment | โหมด **demo** (ล็อก), ข้อมูลบัญชี/QR **ตัวอย่าง** — ห้ามใส่บัญชีจริง |
| Booking | ช่วงเวลา (HH:MM คั่นด้วย ,), จองล่วงหน้าสูงสุด, วันปิด (1=จันทร์ … 7=อาทิตย์) |
| Uploads | ขนาดไฟล์สูงสุด (ไม่เกิน 2 MB) |

## 10. ข้อควรระวัง

- **ห้ามใช้ service_role / secret key** ในเว็บ และห้ามแชร์รหัสผ่าน Admin
- สต็อก ยอดขาย คะแนน สถานะบัญชี และจำนวนการใช้คูปอง แก้ได้ผ่านเมนูที่กำหนดเท่านั้น (ฐานข้อมูลบล็อกการแก้ตรง แม้เป็น Admin)
- ข้อมูลทดสอบทั้งหมดถูกทำเครื่องหมาย **Demo** — ใช้ตัวเลือก "ไม่รวม Demo Data" ในรายงานเมื่อต้องการดูเฉพาะข้อมูลจริง
- ถ้าเปิดหน้า Admin แล้วเห็น 403 ให้ตรวจว่าบัญชีมี `role = admin` และสถานะ `active`
